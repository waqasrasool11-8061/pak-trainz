02 End-to-End Workflow (Start to End Process)

Customer ke order place karne se le kar Trainz me engine drive karne tak ka complete safar:

Step 1

Store Order

Customer pak-trainz.vercel.app par cart checkout karta hai (EasyPaisa/JazzCash). Admin approve karta hai to unique License Key generate hoti hai.

Step 2

Client App Launch

Customer TRS-DEP-PAK-Launcher.exe open karta hai aur apna Email + License Key enter karta hai.

Step 3

Hardware ID Binding

App user ke CPU, Motherboard UUID aur Windows Machine GUID ka SHA-256 hash (HWID) bana kar server ko send karti hai.

Step 4

Server Verification

Server check karta hai: Agar key active hai aur HWID match hai (ya 1st time activation hai) to encrypted temporary install token bhejta hai.

Step 5

Trainz Auto-Detect

App Registry ya standard drives se Trainz 2019 / 2022 ka folder dhoondhti hai jahan TrainzUtil.exe mojood hota hai.

Step 6

Direct Injection

App secure stream download karke foran TrainzUtil.exe install run karti hai. Trainz model ko database me compile karta hai, aur temp cache delete ho jata hai.

Trainz Simulator me addon install karne ka standard tariqa TrainzUtil utility hai. Hamara Client App is tariqay se file inject karega taake customer usay churra na sake:

// 1. Client App requests secure temporary chunk from server
const stream = await fetchDecryptedPayload(token, hwid);

// 2. Stream is piped into a hidden temporary pipe or locked Windows Temp file

// 3. Client App silently triggers TrainzUtil to compile into Trainz internal database

// 4. Secure instant wipe (Zero file remains on disk)

// Result: Locomotive is now playable inside Trainz, but no .cdp file exists on user's hard drive!
